# IndicF5 preset prompt clips

These five clips are the official IndicF5 demo prompts from
[AI4Bharat/IndicF5](https://github.com/AI4Bharat/IndicF5/tree/main/prompts)
(MIT license, © AI4Bharat / IIT Madras). They are bundled so the built-in
IndicF5 preset voices work out of the box, together with the official
transcripts from the IndicF5 demo space.

| File | Preset | Language |
|---|---|---|
| `TAM_F_HAPPY_00001.wav` | Kavya | Tamil |
| `KAN_F_HAPPY_00001.wav` | Kiran | Kannada |
| `MAR_F_WIKI_00001.wav` | Meera | Marathi |
| `MAR_M_WIKI_00001.wav` | Arjun | Marathi (male) |
| `PAN_F_HAPPY_00001.wav` | Simran | Punjabi |

Every preset can speak **all 11** IndicF5 languages — the clip defines the
voice timbre; the text you generate (and its language) is separate. This is a
first-class mode of the model (cross-lingual prompting).
