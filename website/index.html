Direction, not guesswork

Pick an emotion. The assistant writes the direction.

Fifteen one-click emotions set the delivery instantly. Want it sharper for this exact script? A small local LLM (Qwen3, Apache-2.0) reads your script + the emotion and writes the precise delivery prompt the voice engine understands — and can tidy your script with punctuation and natural pauses. Runs on your GPU, 100% offline.

Everything included

A full studio, not a demo

Every feature works end-to-end on your machine — no mock buttons, no paywalls.

Clone from 5 seconds

Drop in a short clip — audio or video. HeyVoices cleans it, transcribes it, checks quality, and builds a reusable voice.

Video → voice

Point it at an MP4 and it strips the audio, removes music-free silence, and clones the speaker — one click.

Voice design

Describe a voice — “calm narrator, deep and slow” — and the Qwen engine invents it from text alone.

35+ languages

English, Chinese, Japanese and more — plus 11 Indian languages (Telugu, Tamil, Odia, Kannada, Malayalam, Marathi, Punjabi, Gujarati, Bengali, Assamese, Hindi) with zero-shot cloning, powered by IndicF5.

Story & audiobook mode

Give every line its own voice and pacing, render the whole script, and export chaptered M4B or MP3 with subtitles.

Batch + API + MCP

Load a CSV of lines and render the queue, or wire the local REST API / MCP server into your apps, agents and games.

Fits an 8 GB laptop GPU

Single-GPU queue, live VRAM telemetry, one-click model unload — tuned to run comfortably on an RTX 4060 Laptop.

Emotions + AI prompt crafting

15 one-click emotions — Excited, Whisper, Devotional, Game NPC and more. An optional small local LLM (Qwen3) turns your script + emotion into the exact delivery prompt, and tidies scripts with natural pauses.

Updates in the app

HeyVoices checks for a new release at startup, shows what changed, and downloads + installs it from inside the app — no reinstall dance.

Private by construction

The backend binds to 127.0.0.1 only. Your audio, voices and text never leave your machine — there is no cloud to leak to.

Three steps

From zero to your own voice

1

Install & launch

Run the Windows setup (or the portable build). First launch installs the Python environment once — after that everything works offline.

2

Add a voice

Pick a preset, clone from a 15–30 second clip, or describe a brand-new voice. The guided tour walks you through it.

3

Generate anything

Type, hit Generate — keep every take. Optionally let the assistant craft the delivery or tidy the script. Export WAV / MP3 / OGG / FLAC, subtitles, or a chaptered audiobook.
